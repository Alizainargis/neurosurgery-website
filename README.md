# Dr. Khalid Khan Zadran — Neurosurgery Website

Responsive React + Tailwind CSS website inspired by the supplied reference screenshots.

## Run locally
1. Install Node.js 18 or newer.
2. In this folder, run `npm install`.
3. Run `npm run dev` and open the local URL printed by Vite.
4. Run `npm run build` to create a production build in `dist/`.

## Included
- Responsive navigation and mobile menu
- Animated hero, cards, section reveals, FAQ accordion and form feedback
- Services, procedures, about, appointment and contact sections
- Phone and WhatsApp links
- Demo appointment form that intentionally does not send or store user information
- Doctor image cropped from the reference screenshot provided for this project

## Notes
The language control is a visual toggle only; translations are not implemented. Social links point to generic platform homepages because specific profile URLs were not provided. Confirm clinic information and image usage before publishing.
